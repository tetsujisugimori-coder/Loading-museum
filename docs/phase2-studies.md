# 第2期：作品要件と検証記録

Issue #39 / Draft PR #40。全作品は独自のCanvas計算・図柄で構成し、外部画像、音声、原典のコードを使いません。具体的な単一作品の複製ではなく、一般的な技法からの着想です。描画上限は星180、群れ100、書き込み150点、画素120×75。選択中だけマウントし、画面外・タブ非表示・動き低減で自動描画を止めます。

## 指摘と検証追記

独立レビューの位相初期化、Flockingの速度無効、色順Resetを修正。プラズマの一時停止・速度変更前後の画素、群れの描画位置、インクの再入力色順をモックCanvas回帰で確認。画面外と閉室でRAFを取消すテスト、格子の弾力・減衰の挙動テストを追加。Elasticには無効だった速度操作を残さず、必要な弾力・減衰・密度を提供する。星・メタボール・群れはCanvas上の矢印、格子は矢印、万華鏡・インクは矢印とEnterの代替操作を追加。

改良後のEdge実画面でメタボール、弾性格子のドラッグ、万華鏡の模様、グリッチ、Pixel Dissolve途中、Tile Flip途中と切替後を視認。前述のプラズマとトンネルの初期表示も確認済み。ただしこれは12作品の全条件を網羅する証明ではなく、実機タッチ、画面外停止や動き低減のブラウザ実測、個々の速度・パラメータ全域の描画比較は未確認。

2026-10-30 最終確認: lint、通常 build（型検査を含む）、静的テスト49件は成功。全体 Vitest は114成功・既存 WAAPI ギャラリー1件が5秒制限でタイムアウトし失敗。同ファイル単独・1 workerでは11件成功。並列時の失敗は解消済みとは断定しない。修正後 Edge で Starfield の描画も確認。iPhone実機、全12作品のタッチと全パラメータの実描画比較は未確認。
